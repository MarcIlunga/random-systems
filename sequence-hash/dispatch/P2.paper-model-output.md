## Exact paper model used

From [2014-578.pdf](/Users/marcilunga/Documents/tob/research/random-systems/sequence-hash/2014-578.pdf):

- §2.2 compression family:

  > “For a keyed function \(f : \{0,1\}^c \times \{0,1\}^b \to \{0,1\}^c\)…”

  Its first component is the key. Thus the deterministic family has domain \(C\times B\), while sampling \(K\) exposes \(f_K:B\to C\).

- §2.1 ideal systems:

  > “Similarly, for a finite domain \(\{0,1\}^b\) we denote by \(\mathbf r\) a system realizing a function chosen uniformly from \(\mathcal F(b,c)\). Finally, we also consider a system \(\mathbf f\) realizing a function chosen uniformly from \(\mathcal F(c+b,c)\).”

  Therefore the ideal compression table has domain \(C\times B\), but Theorem 1’s PRF comparator is the fixed-input URF \(\mathbf r:B\to C\).

- §2.2 cascade, unnumbered display:

  \[
  \operatorname{Casc}^f(K,m_1\|\cdots\|m_\ell):=y_\ell,\qquad
  y_0:=K,\quad y_i:=f(y_{i-1},m_i).
  \]

  The paper explicitly sets \(\operatorname{Casc}^f(K,\lambda):=K\).

- §2.2 NMAC, unnumbered display:

  \[
  \operatorname{NMAC}^f((K_1,K_2),M)
  :=f(K_2,\operatorname{Casc}^f(K_1,M)\|0^{b-c}).
  \]

  Thus \(K_1\) is the inner cascade IV/key and \(K_2\) keys the final call; Theorem 1 samples them independently and uniformly.

- §2.2 HMAC, unnumbered display:

  \[
  \operatorname{HMAC}^f(K,m)
  :=\operatorname{Casc}^f\!\left(
    IV,\,
    K_2\|\operatorname{Casc}^f(IV,K_1\|m)\|fpad
  \right),
  \]

  where

  \[
  (K_1,K_2):=(K\oplus ipad,K\oplus opad).
  \]

  HMAC therefore uses the public hard-coded \(IV\), with the derived keys prepended as message blocks rather than supplied through \(f\)’s key input.

- §2.2 PRF security:

  > “\((\varepsilon,t,q,\ell)\)-secure PRF, if for any adversary \(A\) running in time \(t\) and making at most \(q\) queries, each of length at most \(\ell\) … a uniformly random key \(K\leftarrow\{0,1\}^c\), we have \(\Delta^A(G_K,\mathbf R)\le\varepsilon\).”

  Nonadaptive security is the same condition restricted to adversaries that choose all queries before seeing outputs. For fixed-input functions, the paper omits \(\ell\) and compares against \(\mathbf r\).

## Exact bounds

- §3.1 Proposition 1:

  > “Let \(f:\{0,1\}^c\times\{0,1\}^b\to\{0,1\}^c\) be a compression function… for any \((\varepsilon',t',q,\ell)\)-NA-PF-PRF adversary \(A\) against \(\operatorname{Casc}^f\), \(T^A\) is an \((\varepsilon_{\mathrm{na}},t,q)\)-NA-PRF adversary against \(f\) such that  
  > \(\varepsilon'\le \ell q\varepsilon_{\mathrm{na}}\) and \(t=t'+\widetilde O(\ell q)\).”

- §3.1 Theorem 1, Eq. (1):

  \[
  \varepsilon'
    =\varepsilon+(\ell+1)q\varepsilon_{\mathrm{na}}
      +\frac{q^2}{2^c},
  \qquad
  t=t'+\widetilde O(\ell q).
  \]

  Assumptions: \(f\) is both an \((\varepsilon,t,q)\)-secure adaptive PRF and an \((\varepsilon_{\mathrm{na}},t,q)\)-NA-secure PRF.

- Appendix A, Lemma 5:

  \[
  \Delta^{A_1}(\operatorname{Casc}^f_K,\mathbf R)
    \le \ell\cdot\Delta^{A_2}(qf_{\bar K},q\mathbf r).
  \]

  Its length-position hybrid is Eq. (9); choosing the hybrid index uniformly produces the factor \(\ell\).

- Appendix A, Lemma 6:

  \[
  \Delta^{A_2}(qf_{\bar K},q\mathbf r)
    \le q\cdot\Delta^{A_3}(f_K,\mathbf r).
  \]

  Its oracle-index hybrid is Eq. (10); choosing the oracle index uniformly produces the factor \(q\).
