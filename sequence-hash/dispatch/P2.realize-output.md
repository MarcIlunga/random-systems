Two independent type-level blockers remain:

- `macStep` has no `K` parameter, while `ofStep` is deterministic. `sequenceMACReal` only samples the chaining key `k : C` inside `compReal`; it cannot independently sample or receive a length-`κ` byte key.
- `compReal f` exposes the fixed function `f k : B → C`. Actual MD iteration needs changing chaining inputs:
  `mdIterate f iv [b₁,b₂] = f (f iv b₁) b₂`.
  A converter querying only `B` cannot submit `(currentChainingValue, block)` and therefore cannot evaluate this fold.

A realizable interface would require both:

- A MAC key `K` supplied to `macStep`, or a probabilistic converter that samples `K`.
- Compression queries of type `C × B` (or an equivalent resettable stateful compression resource), exposing `(c,b) ↦ f c b`.

Because this changes the frozen `macStep` signature and the resource/system types, I did not encode an all-zero key or a stateless approximation.
