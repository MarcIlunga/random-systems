# Versioned SequenceHash research

The construction changed materially between the public draft and the stable
specification. Research records are therefore indexed by specification version
and are never silently retargeted to a later construction.

- [`v0.1.0`](v0.1.0/README.md) records the scope and location of the existing
  formalization and its historical proof plan.
- [`v1.0.0`](v1.0.0/README.md) records the stable construction's new
  pen-and-paper security program.

The corresponding immutable specification texts are kept in
[`../specs`](../specs/README.md).
