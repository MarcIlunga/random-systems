# SequenceHash sources

The current stable C2SP specification and the earlier draft used by the Lean
development are preserved in the [versioned specification archive](specs/README.md).

- Stable specification: [C2SP SequenceHash v1.0.0](https://c2sp.org/sequencehash)
- Upstream repository: <https://github.com/C2SP/C2SP>
- Upstream path: `sequencehash.md`
- Stable pinned commit: `3bc97b2329fee167f7ff39efbbbc316c84876105`
- Stable snapshot: [`specs/v1.0.0/sequencehash.md`](specs/v1.0.0/sequencehash.md)
- Draft snapshot used by the current Lean files:
  [`specs/v0.1.0/sequencehash.md`](specs/v0.1.0/sequencehash.md)

The compatibility file [`sequencehash.md`](sequencehash.md) remains the
v0.1.0 text. This preserves the meaning of existing source links while the
v1.0.0 model is developed separately.

The PDF papers in this directory were supplied locally and are not fetched as
part of this formalization.
