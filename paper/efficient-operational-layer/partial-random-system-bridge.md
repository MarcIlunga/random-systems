# The route-safe bridge to partial random systems

## 1. Purpose and theorem boundary

The finite contextual algebra does not by itself prove that ordinary
random-system connection is its cost erasure.  A physical matching performs
canonical routing work.  If that router is allowed to exhaust, connecting two
otherwise responsive behaviors can create a new nonresponse that is absent
from cost-free strict DDS feedback.

This note isolates and closes that gap for the canonical router.  It does
three things.

1. It defines a standard-Borel carrier of laws over partial DDSs with an
   explicit semantic observation for strict nonresponse.
2. It proves that its observational equivalence is a congruence for strict
   connection.
3. It identifies a route-safe operational subalgebra in which canonical
   routing is fully charged but its quota is derived to dominate every
   possible routed action.  On that subalgebra, behavioral operational
   connection maps exactly to strict partial random-system connection.

An intentionally underfunded communication resource remains expressible as
an explicit node.  It is then part of the system being connected, not hidden
inside the structural connection operator.  The theorem below does not
identify a general underfunded physical matching with a cost-free abstract
wire.

## 2. The partial DDS carrier

Fix countable encoded input and output alphabets `X` and `Y`.  Put

```text
Y_bot = Y + {undefined}.
```

Enumerate the countable set `X^+`.  The full function space

```text
Y_bot^(X^+)
```

with its countable product sigma-algebra is standard Borel.  Let `DDS(X,Y)`
be the subset of functions `s` satisfying prefix closure:

```text
s(x^n) != undefined
  => s(x^j) != undefined for every j <= n.
```

### Lemma 2.1 (standard-Borel DDS space)

`DDS(X,Y)` is a Borel subset of `Y_bot^(X^+)` and is therefore standard
Borel.  Its Borel sigma-algebra is generated by the evaluation events

```text
E_(h,y) = {s | s(h)=y},
U_h     = {s | s(h)=undefined}.
```

**Proof.** For each pair `(x^j,x^n)` with `x^j` a prefix of `x^n`, the
forbidden event

```text
{s | s(x^n) != undefined and s(x^j)=undefined}
```

is a countable union of finite-coordinate cylinders.  Prefix closure is the
complement of the countable union of all forbidden events.  Hence it is
Borel.  The displayed evaluations are precisely the restricted coordinate
cylinders.

## 3. Maximal strict transcripts

A deterministic environment is a prefix-closed partial map

```text
e : Y^* -> X.
```

We do not impose the common-domain compatibility premise used for finite
common-domain PDSs.  Instead, interaction has one of three maximal outcomes:

```text
Inf((x_1,y_1),(x_2,y_2),...)

EnvStop((x_1,y_1),...,(x_n,y_n))

SysStop((x_1,y_1),...,(x_n,y_n); x_(n+1)).
```

`EnvStop` means that `e(y^n)` is undefined.  `SysStop` means that the next
query `x_(n+1)=e(y^n)` is defined but `s(x^(n+1))` is not.  The pending query
is retained because the environment knows which query it issued even though
no response appears.  No ordinary response symbol is added.

For a fixed `e`, the stop tag and pending query are deterministic functions of
the ordinary finite pair transcript: evaluate `e` on the last response
history.  Hence this maximal presentation makes strict nonresponse explicit
without changing equivalence by all environments.

Let `T(X,Y)` be the disjoint union of the countable set of finite tagged
outcomes and the Baire space of infinite pair streams.  It is standard
Borel.  Write

```text
run_e : DDS(X,Y) -> T(X,Y)
```

for the maximal interaction map.

### Lemma 3.1 (transcript measurability)

For every deterministic environment `e`, `run_e` is measurable.

**Proof.** A finite pair prefix fixes finitely many DDS evaluations and
environment-table values.  `EnvStop` adds one fixed undefined environment
evaluation and `SysStop` adds one DDS nondefinition event `U_h`.  Infinite
cylinders are generated by their finite prefixes.  The inverse image of every
generator is therefore an evaluation cylinder or a finite intersection of
such cylinders.

A partial PDS is a probability measure `mu` on `DDS(X,Y)`.  Define

```text
mu ~=obs nu
```

when `(run_e)_* mu = (run_e)_* nu` for every deterministic environment `e`.
A partial random system is an equivalence class under `~=obs`.

On a finite common domain and compatible environments, `SysStop` is absent
and this definition restricts to the usual transcript equivalence.  The
additional terminal form is exactly the strict-partial extension required by
metered nonresponse.

## 4. Strict connection on DDSs

Let a boundary alphabet be a tagged disjoint union over oriented ports.  Fix
two compatible opposite-polarity boundary occurrences `p,q`.  For a DDS `s`,
the strict connection `connect_(p,q)(s)` is evaluated by an expansion
transducer.

For each external query:

1. append it to the expanded query history of `s`;
2. if `s` is undefined, return strict nonresponse;
3. if the answer is at a boundary other than `p,q`, return that first visible
   answer;
4. if the answer is at `p` or `q`, translate its payload to the input alphabet
   of the opposite endpoint, append that hidden query, and continue;
5. if the hidden chain is infinite, return strict nonresponse.

The expanded history persists between external queries.  Formally, the value
of the connected DDS on an external input history is computed by replaying
that finite history from the empty expanded history and retaining every hidden
query and answer generated along the way.  Thus the construction is a
function of the external input history, not an implementation with
unmentioned mutable state.  If an earlier external prefix has no answer, no
extension is evaluated.  This proves prefix closure.

### Lemma 4.1 (measurability of strict connection)

```text
connect_(p,q) : DDS(B) -> DDS(B \ {p,q})
```

is measurable.

**Proof.** The event that a fixed external history receives a fixed visible
answer is the union, over all finite compatible hidden event strings, of the
finite evaluation cylinders saying that exactly this expansion occurs.
Alphabets are countable, so the union is countable.  The corresponding
nondefinition event is its complement after taking the countable union over
visible answers.

Renaming is coordinate relabeling.  Independent tensor on DDSs interleaves
tagged external queries while advancing only the selected factor's projected
history.  Both maps are measurable by the same finite-cylinder argument.

### Lemma 4.2 (finite connection-order invariance)

Let `E` be a finite legal matching of pairwise distinct boundary endpoints.
Define `connect_E(s)` by the same expansion rule, hiding every event whose
port belongs to an edge of `E`.  For every enumeration
`e_1,...,e_r` of `E`,

```text
connect_E(s)
  = connect_(e_r)(...connect_(e_1)(s)...).
```

**Proof.** Flatten the nested evaluators.  Beginning from the same external
query and expanded history, both descriptions inspect the same uniquely
determined next evaluation of `s`.  If its port is not in `E`, both return it
as the first visible answer.  If its port lies on any edge in `E`, both append
the uniquely matched hidden query and continue.  A finite induction covers a
successful hidden expansion.  If `s` becomes undefined or the expansion is
infinite, neither description returns a visible answer.  The persistent
expanded history after each visible answer is identical, so induction over
external histories proves equality of DDSs.  The argument is independent of
the enumeration.

## 5. Observational congruence

### Theorem 5.1 (strict-connection congruence)

If `mu ~=obs nu`, then

```text
(connect_(p,q))_* mu ~=obs (connect_(p,q))_* nu.
```

**Proof.** Fix an environment `e` for the connected boundary.  Construct a
deterministic lifted environment `lift_(p,q)(e)` for the unconnected boundary.
It maintains the state of `e` and the finite expansion transducer from
Section 4.  When no hidden chain is pending it issues the query chosen by
`e`; after an answer at `p` or `q` it issues the corresponding hidden query;
after another boundary answer it feeds that answer to `e`.  Because its prior
queries are deterministic functions of the output history, this is a DDE of
the required form rather than an extra stateful object.

There is a measurable hiding map on maximal lifted transcripts.  It removes
the `p,q` pairs, converts a finite lifted system stop into the corresponding
outer system stop, converts an infinite hidden tail with only finitely many
outer answers into outer strict nonresponse, and otherwise retains the
infinite outer stream.  For the only nonlocal case, the preimage of a fixed
outer system stop caused by hidden livelock is a countable union over the
position of the last outer answer, followed by a countable intersection
saying that every later lifted answer is at `p` or `q`.  It is therefore
Borel.  Preimages of the remaining finite tags and infinite prefix cylinders
are finite or countable unions of ordinary cylinders.  Pathwise,

```text
run_e(connect_(p,q)(s))
  = hide_(p,q,e)(run_(lift_(p,q)(e))(s)).
```

Pushforward along the two measurable maps.  Observational equivalence gives
equality of the lifted transcript laws, and the hiding pushforward gives the
desired connected laws.

### Theorem 5.2 (parallel congruence)

If `mu ~=obs nu`, then for every law `lambda`,

```text
tensor_*(mu x lambda) ~=obs tensor_*(nu x lambda).
```

**Proof.** Fix a deterministic joint environment and condition on one
deterministic DDS `t` from the second factor.  Simulate every maximal block of
queries addressed to `t` between two queries addressed to the first factor.
There are three cases.

1. The simulation reaches a first-factor query.  Its value is a deterministic
   function of the first-factor answer history and defines the next value of
   a DDE `e_t`.
2. The joint environment or `t` stops before another first-factor query.  The
   derived DDE stops, and a deterministic reconstruction map restores the
   correct joint stop tag and prefix.
3. The simulation makes infinitely many `t`-queries before another
   first-factor query.  The first-factor law is irrelevant; the
   reconstruction map returns that infinite joint transcript.

Consequently the joint transcript is a deterministic measurable
reconstruction of `run_(e_t)(s)` and `t`.  The maps involved are measurable:
the event that the simulation takes any prescribed finite path is a finite
intersection of evaluation cylinders, and the infinite-only case is a
countable intersection/union of those events.  Apply `mu ~=obs nu` for each
fixed `t`; the two resulting conditional transcript kernels are equal.
Their common dependence on `t` is measurable by the preceding cylinder
calculation, so integration with respect to `lambda` proves the claim.  The
symmetric argument handles replacement of the second factor.

Renaming congruence is immediate.  The identity DDS is the typed wire
transducer.  Therefore partial random systems form a system algebra for
renaming, independent tensor, and strict finite connection.

## 6. Why canonical routing needs a domination rule

The exact-cost machine semantics charges a physical matching.  Let the fixed
bit-level router satisfy constants `a_0,a_1,a_S >= 1` such that routing an
encoded event of length `L` uses at most

```text
a_0 + a_1 L work,
L traffic bits,
a_S(L+1) live buffer cells.
```

Every machine event is emitted by a charged transition from a blank output
buffer, so there are fixed constants `c_0,c_1` such that, over any run prefix,

```text
number of machine-emitted events <= c_0 * machine work,
machine-emitted bits             <= c_1 * machine work.
```

Admitted specification responses and blocks are separately bounded by the
call and response-bit reservations.  Bare aliases have no runtime behavior
and are normalized away.

For a normalized graph `G`, let

```text
W_G = sum of all evaluated machine work quotas,
C_G = sum of all admitted specification call quotas,
R_G = sum of all evaluated aggregate specification
      query/response/block-record bit envelopes.
```

Define the canonical routing envelope

```text
RouteWork(G) =
  a_0(c_0 W_G + C_G) + a_1(c_1 W_G + R_G),

RouteTraffic(G) = c_1 W_G + R_G,

RouteSpace(G) =
  a_S(1 + c_1 W_G + R_G).
```

These deliberately loose bounds count every possible routed machine event and
every admitted specification event.  A per-call reservation is first
multiplied by its call envelope, or a sharper declared aggregate traffic grade
is used.  The resulting bounds are fixed polynomials whenever the component
grades and access reservations are fixed polynomials.

### Definition 6.1 (route-safe graph)

A graph is route-safe when **each** canonical physical matching is assigned
an external infrastructure meter with at least the displayed whole-graph
aggregate envelope.  This intentionally redundant assignment avoids making
the theorem depend on a global-router implementation: the total use of all
canonical matchings is below the envelope, so the local use of each one is as
well.  Equivalently, an implementation may enforce one shared aggregate
canonical-routing meter, provided its exact ledger still records the
per-edge traffic and transitions required by the chosen cost model.

Only events crossing an ordinary matched edge are charged to this canonical
plumbing.  An input at an open boundary is delivered directly to its boundary
occurrence; after a closing context is attached, the context's emitted query
is a charged machine event before it crosses the newly created matching.
Thus no uncounted external source is hidden in the envelope.

An explicit link, channel, bus, bandwidth cap, or memory-limited buffer is an
ordinary resource node with its own interface and is not included in this
canonical envelope.

When graphs are tensored or connected, route safety is evaluated on the final
normalized graph.  Public ownership labels of ordinary components are
unchanged.  The canonical router's grade may increase because the final
aggregate envelope increases, but programs cannot inspect grades and the
router could not exhaust under either valid route-safe envelope.

### Theorem 6.2 (canonical routing never exhausts)

In a route-safe graph, a canonical matching cannot be the first exhausted
occurrence.

**Proof.** Every routed event is either machine-emitted or a finite admitted
specification event.  Sum the two event-count and bit bounds above.  The
*aggregate* accumulated work and traffic of all canonical routers remain
below `RouteWork` and `RouteTraffic`; hence so do the corresponding local
coordinates of every edge router.  At most one canonical router is active in
the one-token semantics, and its one live buffer is bounded by `RouteSpace`.
Therefore its next exact charge always fits while the event that caused it is
itself admitted.  Infinite hidden routing cannot evade the argument: a bare
alias has been removed, and every remaining event consumes positive machine
work or a positive specification-call coordinate, so some nonrouter meter
fires first.

Route-safe graphs are closed under renaming, finite tensor, connection, and
converter attachment by recomputing the displayed aggregate on the final
normalized graph.  This recomputation changes a non-observable grade, not an
exact ledger event or public program state.

## 7. Measurable operational denotation with specification seeds

Fix a route-safe metered open graph `G`.  Its sample space is the finite
product of:

- one Bernoulli tape per implementation occurrence;
- one iid uniform seed sequence per specification occurrence;
- any declared standard-Borel initial specification-state laws.

Choose the measurable sampler of the bounded-call oracle contract.  Fixing a
sample makes the entire lifetime graph deterministic and hence produces one
partial DDS `D_G`.

### Lemma 7.1

`D_G` is measurable into the partial DDS space of Section 2.

**Proof.** For a fixed finite external query history, route safety and the
finite component/call meters give a finite deterministic small-step horizon
unless the path consists only of administrative aliases, which normalization
removes.  Machine steps are measurable piecewise maps on countable
configurations.  Oracle steps are measurable maps of the fixed seed and
standard-Borel state through the selected sampler.  The preimage of a fixed
successful evaluation is a finite or countable union over hitting times of
measurable step events; nondefinition is the complement of the union over
encoded responses.  These are the evaluation generators of Lemma 2.1.

Push the product sample law forward:

```text
mu_G = (D_G)_* P_G,
J(G)  = [mu_G]_~=obs.
```

## 8. Finite-cylinder completeness of operational contexts

Let `~=beh,rs` be contextual equivalence formed from route-safe graphs and
route-safe finite coded closing contexts, with the semantic decision
convention factoring through strict cost erasure.  Explicit limited-link
nodes remain allowed; only underfunded *structural plumbing* is excluded.
Although one fixed context has finite grades, the quotient quantifies over
every such context, so it contains arbitrarily large finite lookup tests.
The pointwise quotient may use arbitrary measurable terminal scores to compare
complete outcome laws.  This is not a claim that such a score is free
efficient computation; the asymptotic class uses the separate fixed graded
terminal-scorer definition.

### Lemma 8.1 (compiling a transcript cylinder)

Fix a deterministic abstract environment `e` and one finite cylinder event
of `T(X,Y)`.  There is a finite route-safe operational context whose erased
decision event on every graph `G` is exactly that cylinder event under
`run_e(D_G)`.

**Proof.** A singleton finite cylinder fixes only finitely many response
values.  Along that path, `e` chooses finitely many finite encoded queries.
Hard-code those queries and the expected responses in finite control.  On a
matching response, advance; on a mismatch, stop with decision zero.  Give
the context constant grades large enough to write and route this finite
table.  Its semantic decision map scores the required finite environment
stop, system stop with pending query, or finite prefix event.  This use of a
semantic score is essential for a system-stop cylinder: no timeout response
is injected into the wire semantics.  The finite tagged singletons and finite
prefix cylinders form a countable separating pi-system for the
maximal-transcript sigma-algebra.

### Theorem 8.2 (pointwise full abstraction)

For route-safe graphs `G,H` with the same boundary at fixed `(kappa,b)`,

```text
G ~=beh,rs H    iff    J(G)=J(H).
```

**Proof.**

For the forward implication, if some deterministic environment gives
different maximal-transcript laws, two probability measures differ on a
member of the displayed countable separating pi-system; otherwise the
pi-lambda theorem would make the measures equal.  Lemma 8.1 supplies a
behavioral operational context distinguishing `G` and `H`, a contradiction.

For the reverse implication, condition a finite behavioral context on all its
machine tapes, specification seed sequences, and initial specification
states.  In the one-token semantics its internal computation between
boundary calls is deterministic.  Replaying it from the start therefore
defines a partial DDE: either it issues the uniquely determined next boundary
query, or it stops/diverges internally.  The conditioned closing decision is
a deterministic measurable function of the resulting maximal boundary
transcript and the context's fixed sample.  Target transcript equality gives
equal conditional score laws.  Integrate over the context sample.  Router
reports, owners, and exact ledgers are unavailable because the test factors
through erasure; context-side block or exhaustion is simply one way in which
the derived DDE becomes undefined.

Thus `J` is well-defined and injective on the route-safe behavioral
operational quotient.  Using the finer unrestricted contextual relation would
be wrong: an intentionally underfunded structural router could distinguish
two equal target behaviors by implementation cost.  Such a test must instead
make the limited link an explicit node, in which case its behavior is present
on both sides of `J`.

## 9. The bridge theorem

### Theorem 9.1 (route-safe operational realization)

Let

```text
R_beh^rs(kappa,b;B)
```

be the behavioral contextual quotient of route-safe graphs by route-safe
closing contexts, and define `R_cost^rs` analogously with cost-aware
route-safe contexts.  Then

```text
J_B : R_beh^rs(kappa,b;B) -> RS_partial(B)
```

is an injective system-algebra homomorphism for typed renaming, independent
finite tensor, every legal finite connection, converter action, and identity.
Its image is the route-safe metered operational subalgebra of partial random
systems.

**Proof.**

- Well-definedness and injectivity are Theorem 8.2.
- Renaming and independent tensor are pathwise relabeling and product-tape
  identities, followed by pushforward and Theorem 5.2.
- For connection, normalize the physical graph and couple it with the strict
  expansion evaluator on the same machine tapes, oracle seeds, and initial
  specification states.  Component microsteps and oracle calls agree.  A
  hidden event takes finitely many canonical routing steps physically and one
  administrative expansion step abstractly.  Theorem 6.2 excludes router
  exhaustion, and no clock observes the delay.  A first remaining boundary
  event, component/specification stop, or infinite hidden chain therefore
  agrees pathwise.  Pushforward gives

  ```text
  J(connect_(p,q) G) = connect_(p,q) J(G).
  ```

- Converter action is tensor followed by finite connection.  A bare identity
  normalizes to the target typed wire.

Structural connection-order invariance of normalized graphs and target
congruence make the equations independent of presentation order.

Composing this theorem with the proved cost-erasure homomorphism gives

```text
R_cost^rs(kappa,b)
  --U--> R_beh^rs(kappa,b)
  --J--> RS_partial.
```

Both arrows preserve the full finite system algebra.  The first forgets cost
observations while retaining metered behavior; the second forgets the
route-safe implementation presentation.

## 10. Relation to existing random-system presentations

Finite common-domain PDSs embed by viewing their finite distribution as a
probability measure on the standard-Borel DDS space.  Against compatible
environments, the maximal-transcript law is the ordinary transcript law.

There is also no unintended refinement from the additional, incompatible
environments.  Fix a common deterministic domain `D` and an arbitrary DDE
`e`.  Define the compatible truncation `e|D` to follow `e` while the next
input history lies in `D`, and to stop immediately before the first
out-of-domain query.  The maximal run under `e` is a deterministic function
of the ordinary run under `e|D`: a genuine stop of `e` becomes `EnvStop`,
whereas a truncation forced by `D` becomes `SysStop` with the computable
pending query.  Thus equality against all compatible environments implies
equality against every maximal environment.  The converse follows by
restricting to compatible environments.  Consequently the finite
common-domain carrier embeds faithfully and its renaming, tensor, and legal
connections agree with the restrictions of the selected operations.

The operational carrier also permits:

- countably encoded alphabets;
- infinite-support laws induced by persistent tapes;
- random partial domains caused by strict block or exhaustion;
- infinite maximal interactions.

Identifying this extension with another independently fixed random-system
implementation still requires that the other carrier choose the same
maximal-transcript observation and strict connection.  This is now a carrier
comparison theorem, not an open operational-semantics theorem.

An underfunded communication link is outside `R_beh^rs` only as *structural
plumbing*.  The intended model is not lost: make the link an explicit
metered resource node.  It then remains in the route-safe algebra, and its
possible exhaustion appears honestly in `J` as behavior of that resource.

## 11. Residual refinements

The theorem is sequential and classical.  It does not provide:

1. genuine concurrency or partially ordered events;
2. an API-independent physical communication model;
3. a comparison with a target carrier that treats strict nonresponse
   differently;
4. a uniform finite-code realization of every abstract environment.

Item 4 is neither claimed nor needed.  Pointwise full abstraction compiles
one finite cylinder at a time; asymptotic computational security continues to
quantify only over fixed uniform efficient codes.
